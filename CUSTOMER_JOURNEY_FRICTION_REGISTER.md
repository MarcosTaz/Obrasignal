## Ranking rule

Priority = customer abandonment risk × value blocked / truth risk. Cosmetic preference is not a release blocker.

## Truth boundary

A resolved engine assertion does not prove real customer understanding, willingness to pay, retention, or real economic outcome. Synthetic journey gates only prove deterministic product behavior against an independent oracle. Integration GREEN is not canonical release readiness; `MULTI_USER = NOT_MODELED` remains an owner gap rather than a Customer Journey implementation license.
