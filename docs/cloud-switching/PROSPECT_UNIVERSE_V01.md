# Cloud Switching — Prospect Universe v0.1

Status: public-source research only. **No outreach authorized or sent.**

Scoring uses only evidence visible in public sources. The 10 points for willingness to freeze a forecast are always `UNKNOWN` before a real conversation and therefore score 0 here. Billing/telemetry/business-case points are also 0 unless directly supported; they are not guessed from organization size.

## Stage taxonomy

- `PRE_DECISION`: active tender/renewal/alternatives evaluation; strongest chance to freeze original economics.
- `RENEWAL_OPEN`: active renewal/procurement proves a commercial decision window but not an exit intention.
- `IN_PROGRESS`: migration publicly underway; useful only if original forecast is still preserved.
- `RECENT_DECISION`: tender closed/decision recently made; weaker for prospective forecast freeze.
- `COMPLETED`: bootstrap/schema evidence only, not initial acquisition.
- `ANONYMOUS`: bootstrap only; not prospectable.

## Current acquisition conclusion

The first sweep invalidates a naive assumption: **a VMware renewal notice is not automatically a switching lead**. It proves only a dated economic decision and an installed footprint. The highest-value leads are those with one of:

1. explicit alternatives procurement;
2. licensing/platform restructuring language;
3. current exit/replatforming project with preserved original business case;
4. a near renewal where alternative evaluation can still occur before commitment.

This means trigger scoring needs a second dimension beyond timing: `CHALLENGEABILITY` — how much public evidence exists that the status quo is genuinely open to comparison.

Proposed next scoring addition (hypothesis):
- explicit non-VMware / virtualization alternatives evaluation: +15 challengeability
- architecture/licensing structure explicitly under review: +10
- mechanical VMware extension only: +0

Do not silently add this to the canonical 100-point qualification score until it is tested against a larger trigger sample; use it as a research-priority overlay first.
