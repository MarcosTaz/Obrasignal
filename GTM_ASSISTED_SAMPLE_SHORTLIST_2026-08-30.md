## Safe prospect-use rule

Immediately before showing any item to a real prospect:
1. reopen the official notice/platform;
2. confirm the deadline has not been altered, suspended or closed;
3. confirm the notice/document set still exists and identify any amendment;
4. do not state that the prospect is eligible, should bid, or is likely to win;
5. ask the prospect to classify the item using the evaluation vocabulary: `IRRELEVANT / WORTH_OPENING / WORTH_INVESTIGATING / LIKELY_BID / ALREADY_KNOWN / STALE_OR_INVALID`;
6. record whether value came from discovery, faster triage, explanation, or merely confirmation of something already known.
