# CAUSLEDGER — OUTREACH RESPONSE / OBJECTION PLAYBOOK

## Goal
Convert a reply into evidence, not into premature selling. The next milestone is one qualified historical case and a bounded document sample.

## Positive / curious reply
Reply objective: book a 20-minute discovery and identify the right owner.

Ask:
- who owns customer-change/NRE recovery internally;
- whether one historical case exists;
- approximate economic scale only if they are comfortable sharing;
- whether contract/change/cost documents are available;
- whether finance/commercial/program leadership should join.

Do not request sensitive documents by ordinary reply email before agreeing the secure intake path.

## “We already manage this internally”
Do not argue. Ask whether their current process reliably answers:
- which change costs remain unrecovered;
- what was already credited/paid;
- whether notice deadlines are known;
- whether the evidence package is ready for customer review;
- whether a historical independent back-check would be useful.

Offer one bounded historical-case cross-check, not system replacement.

## “We use SAP / ERP / PLM / claims software”
Position CausLedger as independent reconciliation across existing sources, not a migration. Ask whether the system proves contractual responsibility and prior recovery, or only stores transactions/workflow.

## “Send more information”
Send a one-page explanation containing:
- narrow problem;
- rapid-scan inputs;
- outputs;
- NO CLAIM truth rule;
- security/data handling;
- no system replacement;
- next step: one historical case.

Avoid feature lists.

## “What does it cost?”
State that pricing is scoped after a bounded sample because document volume/complexity matter. Current test range:
- rapid scan: free to €750 depending on friction/scope;
- bounded single-case forensic audit: €2,500–€7,500 + applicable taxes;
- optional success component only by separate agreement.

If the prospect will only proceed with a free proof, trade free scan for strict scope and learning permission, not unlimited work.

## “We do not have claims”
Treat as evidence. Ask one diagnostic question only: whether customer-directed engineering/validation/tooling changes ever create incremental cost after award. If no, close politely.

## “Not interested”
Close the current hypothesis. Record reason if offered. Do not send repeated follow-ups.

## “Wrong person”
Ask for the role, not necessarily personal data: Finance Director, Commercial Director, Program Director, Claims/Contracts Manager or Managing Director.

## “Send us a sample / NDA first”
Send the dossier structure without customer data. Accept a mutual NDA route if reasonable. Do not claim legal sufficiency of any template; obtain appropriate review where needed.

## Document-sharing readiness reply
Before receiving files confirm:
- authorized sender/contact;
- exact case/sample scope;
- secure transfer channel;
- permitted storage/retention;
- whether customer/OEM names may be retained in case metadata;
- whether NDA/DPA is required.

Then request only the minimum sample in `DISCOVERY_AND_INTAKE_PACK.md`.

## Follow-up rule
One concise follow-up after an appropriate business interval if no reply. It must add information or reduce friction, not repeat the first email. Example value-add themes:
- “NO CLAIM is a valid output”;
- one-case historical cross-check;
- no ERP replacement;
- specific NRE/change-cost example.

After a second non-response, mark `NO_RESPONSE` and rotate the message/ICP before further contact.

## Learning codes
Record one primary code per interaction:
`PAIN_CONFIRMED`, `NO_PAIN`, `WRONG_BUYER`, `NO_DOCUMENTS`, `SECURITY_BLOCK`, `LEGAL_BLOCK`, `BUDGET`, `PRICE`, `TIMING`, `INCUMBENT_PROCESS`, `NO_TRUST`, `NO_RESPONSE`, `SAMPLE_AGREED`, `SCAN_AGREED`, `PAID_AUDIT_INTEREST`.
