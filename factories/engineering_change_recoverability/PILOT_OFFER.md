# Assisted Pilot Offer v0.1 — Engineering Change Recoverability Assurance

State: commercial hypothesis for controlled T2 exposure; not yet validated by WTP.

## One-line offer

We independently reconcile recent customer-driven engineering changes against technical revision evidence, causal cost, mitigation, commercial terms, notice/approval requirements, customer PO/price updates and payment — to find evidence-backed value that is unclaimed, under-claimed or at risk before it disappears.

## What this is not

- not PLM replacement;
- not ERP replacement;
- not a generic claims consultant;
- not automatic legal advice;
- not a promise that every engineering change is recoverable;
- not a migration project.

Correct EUR 0 is an acceptable result.

## Pilot scope

Default hypothesis:
- 1–2 active customer programs;
- 25–50 engineering changes;
- retrospective window: previous 6 months;
- optional 4-week live monitoring slice;
- assisted human review throughout.

## Baseline-first method

Before searching for incremental value, freeze the customer's existing truth for each change:
- expected recovery;
- quoted amount;
- approved amount;
- invoiced amount;
- paid amount;
- open/disputed amount.

Only value above that baseline can be represented as incremental discovery.

## Deliverables

1. Engineering Change Recovery Ledger — one line per change and cost exposure.
2. Evidence graph — exact source supporting change, revision, cost, causality, mitigation, contract/notice and payment states.
3. Missing-evidence register.
4. Deadline / prior-approval risk register.
5. Reconciliation: expected → quoted → approved → invoiced → paid.
6. Top 3–5 evidence-ready commercial action packages.
7. Executive pilot report separating:
   - recoverable;
   - non-recoverable;
   - unknown;
   - mitigated;
   - already paid;
   - duplicate/already claimed.

## Pilot success metrics

Primary:
- incremental evidence-supported recoverable value identified;
- value at risk preserved before notice/approval expiry;
- incremental cash actually recovered after customer action.

Guardrails:
- zero fabricated entitlement;
- zero duplicate recovery;
- zero unsupported positive recovery classifications in human-reviewed sample;
- all positive amounts traceable to exact evidence.

Secondary:
- quote-to-approval aging;
- approval-to-PO aging;
- PO-to-invoice aging;
- invoice-to-cash aging;
- percentage of ECs with complete evidence chain;
- commercial-review hours per EC.

## Commercial hypothesis to test — not validated pricing

Pilot anchor hypothesis:
- EUR 2,500 fixed assisted audit fee;
- credited against a 10% success fee on incremental cash recovery attributable to accepted pilot findings.

This is a test anchor, not proven WTP. No success fee on value already known, already claimed or already scheduled for payment before the pilot baseline.

## Decision rule

Proceed to recurring monitoring only if the pilot proves one or more of:
- material incremental recovery;
- material rights preserved from expiry;
- measurable reduction in unresolved commercial open-item aging;
- repeatable evidence gaps across changes.

Otherwise record zero/low value and do not manufacture a subscription case.
